# Editing the ComedyShorts website

A short guide for the team. Most updates take a couple of minutes and need no code.

## 1. Log in

1. Go to **https://app.pagescms.org** and sign in (with GitHub, or with the email invite you received).
2. Open the **comedyshorts-berlin** project.
3. The left sidebar shows the sections you can edit: **Shows, Testimonials, Players, Photo gallery, Site settings.**

Every **Save** publishes to the live site automatically. Give it **1–2 minutes**, then reload the site (Ctrl+F5 / pull-to-refresh on phone). If you make a mistake, just edit it again and save — every save is kept in the history, so nothing is ever lost.

## 2. What to edit where

| I want to… | Go to | Notes |
| --- | --- | --- |
| Add / change a show date | **Shows** → *Add an entry* | Date, times, title, prices. Past shows disappear by themselves the day after. |
| Change ticket prices | **Shows** → the show → *Price online* / *Price at the door* | Currently €12 online, €14 at the door. Set per show. |
| Link a show to its own ticket page | **Shows** → *Ticket link for this show* | Paste the show's YesTicket page. If empty, *Buy Tickets* goes to the YesTicket overview. |
| Add an audience quote | **Testimonials** → *Add an entry* | Quote + "First name I." The red banner on the home page cycles through them in order. |
| Add / update a player | **Players** | Name, photo, role, short bio (EN + DE). Tick **Featured** for the one person shown big at the top of the Players page. |
| Add show photos | **Photo gallery** → *Add an entry* | One album per show: title, date, then upload several photos at once. Newest album should go **first** — it opens automatically. |
| Change the video on the home page | **Site settings** → *Video from the last show* | Paste a YouTube or Vimeo link (unlisted is fine). |
| Put in the official logo | **Site settings** → *Logo* | Transparent PNG or SVG. Leave empty to show the text logo. |
| Change the ticket portal link | **Site settings** → *Ticket portal link* | Used by the big button on the Shows page. |

## 3. Tips

- **German fields** can be left empty — the site then shows the English text on the German version.
- **Photos:** keep each file under about 500 KB (resize to ~1600 px wide before uploading). Big files make the site slow on phones. Portrait photos for players, landscape for the gallery.
- **Videos:** prefer YouTube/Vimeo over uploading a video file — GitHub is not a video host. Visitors see a "Play video" button first; the video only loads from YouTube when they click (privacy rules in Germany).
- **Quotes:** only use real audience comments, first name + initial.
- **Times:** 24-hour format, e.g. `19:30`.

## 4. Other text on the site

Fixed wording (the hero text, About page, FAQ, private events, legal pages) is not in the CMS yet. Send changes to Will for now — or ask if you'd like those sections added to the CMS as well.

## 5. If something looks wrong

1. Wait 2 minutes and hard-refresh (Ctrl+F5).
2. Check the entry you just saved for an empty required field or a link that doesn't start with `https://`.
3. Still broken? Tell Will which section you edited and when — every change can be rolled back.
